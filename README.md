# GPU–CPU Offloading for Deep Neural Network Training

Technical analysis of the paper:

O. Beaumont, L. Eyraud-Dubois, and A. Shilova,
"Optimal GPU-CPU Offloading Strategies for Deep Neural Network Training."

This course project examines GPU memory optimization during DNN training,
with a focus on activation offloading, scheduling, NP-hardness, and the
dynamic-programming-based optimization approach proposed in the paper.

## Contents

The report covers:
- Background on GPU memory constraints in DNN training
- Checkpointing and activation offloading
- The offloading problem formulation and complexity result
- Greedy and dynamic-programming-based solution approaches
- Detailed analysis of the proposed dynamic programming algorithm
- Critical discussion of assumptions and limitations
